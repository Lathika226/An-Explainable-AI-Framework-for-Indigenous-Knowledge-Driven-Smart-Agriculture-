# Indigenous Knowledge Corpus

Populate this directory only with knowledge that has traceable sources.

Recommended metadata for each record:

- region
- state
- district
- crop
- crop_stage
- season
- soil_type
- problem
- practice
- purpose
- evidence
- source
- source_url
- validation_status
- reviewer
- review_date
- language

Do not add invented practices.

The backend currently supports lexical retrieval. Add pgvector embeddings and semantic retrieval once the corpus is available.
